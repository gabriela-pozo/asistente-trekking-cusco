# Cómo usar Abra Travel: manual de una página

Para el vendedor que responde consultas de viajeros. En la app, el mismo texto está en el botón **¿Cómo se usa?** de la cabecera.

## Tres pasos

1. **Pega** el mensaje del viajero tal como llegó.
2. **Pulsa «Preparar respuesta»:** verás el mensaje en su idioma con los precios de tu tarifario.
3. **Revisa** las advertencias y «Lo que entendimos», edita si hace falta y copia o abre WhatsApp: **ningún mensaje se envía solo**.

## Además

- Después marca la consulta como **cotizada** o **reservada** para que el Tablero aprenda.
- Si falta algo, la respuesta pide la fecha, el trek o el nivel.
- Si el modelo no responde se usa el de respaldo y luego un ejemplo guardado, y la app lo avisa.
- Para cambiar precios: **Mi agencia**.

## Dónde está cada cosa

| Página | Para qué sirve |
| --- | --- |
| Consulta | Pegar el mensaje, revisar la respuesta y ajustar el paquete |
| Tablero | Tu semana y cómo van las consultas (datos de demostración) |
| Fuentes | De dónde sale cada dato de la respuesta |
| Mi agencia | Tarifario, extras, horario y meta semanal |
| Sistema | Qué modelo responde y con qué datos |
| Piloto | Alcance y límites de la demo |
